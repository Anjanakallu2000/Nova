# NOVA UAE — Static E-commerce Portfolio

Original fictional UAE women's fashion e-commerce project.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- localStorage for demo cart and wishlist
- JSON-LD structured data
- robots.txt + sitemap.xml

## Run
Open `index.html` directly in a browser. No build step or server is required.

## Main pages
- index.html
- shop.html
- category.html
- product.html
- about.html
- blog.html
- article.html
- contact.html
- cart.html

## Notes
This is a demonstration site. Checkout does not process real payments.
The example canonical domain is `https://www.novauae.example/`; replace it before deployment.
GA4, Search Console and Meta Pixel placeholders are comments only; add real IDs only after deployment and consent configuration.
Product imagery is intentionally represented by original CSS editorial placeholders so the project has no bundled copyrighted campaign images.
